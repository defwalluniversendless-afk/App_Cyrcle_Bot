# Круг в Telegram: мини-апп + бот с уроками

В папке:
- `index.html`, `bgm.mp3` — приложение (держи их рядом)
- `bot.py`, `courses.py` — твой бот с уроками и тестами, к которому я добавил веб-сервер для мини-аппа
- `requirements.txt`, `.env.example`

Один и тот же `index.html` работает и в Telegram, и в обычном браузере.

## Как подписка попадает в мини-апп
1. Мини-апп открывается из бота и отправляет серверу подпись Telegram (initData).
2. `bot.py` проверяет подпись: так id человека нельзя подделать.
3. Бот спрашивает закрытый канал (`get_chat_member`, та же проверка, что у уроков) и отвечает «подписка есть» или «нет».
4. В приложении появляется полная версия. Когда подписка закончится и бот подписок уберёт человека из канала, приложение закроет полную версию само. Статус обновляется при каждом открытии и возврате в приложение, ответ кэшируется на минуту.

Пока в приложении закрыто по подписке: все уроки кроме первого, вкладки «Привычки» и «Развивай себя». У человека без подписки там кнопка «Открыть по подписке», которая ведёт в `@habirov_cyrcle_bot`. Статус виден в профиле. Новые платные разделы подключаются к тому же статусу одной проверкой.

Условие одно: бот из `.env` должен быть админом в закрытом канале (как и раньше для уроков).

## Запуск
1. Заполни `.env` по образцу `.env.example` и запусти:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
   Бот поднимает веб-сервер на порту `PORT`.
2. Приложению нужен https-адрес. Два пути:
   - **Всё на одном сервере.** Если у хостинга бота есть публичный https-адрес для порта `PORT`, положи `index.html` и `bgm.mp3` рядом с `bot.py` и поставь `WEBAPP_URL=https://твой-адрес/?v=1`. Сервер сам отдаёт приложение, а запросы идут на тот же адрес.
   - **Приложение на GitHub Pages.** Загрузи туда `index.html` и `bgm.mp3`, а `WEBAPP_URL` укажи на Pages. В `index.html` найди строку `window.KRUG={api:'',subBot:'...'}` и впиши в `api` публичный адрес бота (`https://адрес-бота`). В `.env` поставь `ALLOW_ORIGIN=https://имя.github.io`.
3. Открой бота: /start → «Открыть Круг».

Telegram кэширует страницу. После каждой загрузки нового `index.html` меняй число в адресе (`?v=2`, `?v=3`) и обновляй `WEBAPP_URL`.

## Полный экран
Включается из кода: при запуске на iPhone и Android приложение просит Telegram открыть его на весь экран (Bot API 8.0). Отступы под кнопки Telegram сверху подстраиваются сами. В Профиле → Настройки есть переключатель «Полный экран». На компьютере режим не включается.
